Setup: hosting and the sheet

This page is static. It saves your choices in your own browser and exports a file. If you want everyone's inputs collected in one place before the meeting, paste a Google Apps Script endpoint below; each change is then also appended to a Google Sheet, no login needed for anyone.

How to create the endpoint (ten minutes)
  1. New Google Sheet. Extensions, Apps Script. Replace the code with the block below. Save.
  2. Deploy, New deployment, type Web app. Execute as: Me. Who has access: Anyone. Deploy, copy the URL, paste it above.
  3. Everyone opens this page from the hosted link, types their name at the top, and changes what they disagree with. Rows land in the sheet with a timestamp.
function doPost(e){
  var s = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  var d = JSON.parse(e.postData.contents);
  s.appendRow([new Date(), d.who, d.item, d.value, d.note]);
  return ContentService.createTextOutput("ok");
}
Hosting
  • GitHub Pages publishes from a public repository on the free plan; a private repository needs a paid plan. This content is not for a public repository.
  • Fastest private-enough option: Netlify Drop or Cloudflare Pages, drag the folder, get an unguessable URL. No login for viewers. Add Cloudflare Access (free for a small team, email one-time code) if a lock is wanted later.
  • Put all four files in the same folder so screen IDs link to the wireframes.
